# Infraestrutura

Este diretório receberá infraestrutura declarativa e runbooks depois que os
ADRs de deployment e dados forem aceitos.

Não devem ser versionados aqui segredos, arquivos de estado, credenciais ou
dados de produção. Mudanças de infraestrutura seguirão revisão por pull request
e terão plano de aplicação e rollback explícitos.
