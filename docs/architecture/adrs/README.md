Os ADRs registram decisões que alteram estrutura, segurança, operação ou custo.

| [0004](0004-low-cost-cloud-deployment.md)  | Deployment cloud de baixo custo       | Proposed |

## Ciclo de vida

- **Proposed:** recomendação aguardando revisão.
- **Accepted:** obrigatória para a implementação.
- **Rejected:** avaliada e não escolhida.
- **Superseded:** substituída por outro ADR.

Mudanças em ADR Accepted exigem novo ADR que descreva migração e consequências.
