# NexoDesk Web

Local reservado para o frontend Angular. A aplicação será inicializada após a
aprovação do contrato da primeira fatia vertical.

Responsabilidades esperadas:

- experiência de solicitantes, atendentes e administradores;
- autenticação e seleção segura da organização;
- consumo exclusivo do contrato público da API;
- acessibilidade, responsividade e telemetria sem dados sensíveis.
